# Campfire 1.1.0 Cross-Platform Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and verify Campfire 1.1.0 for Windows x64, RPM x86_64 and AppImage x86_64, publish the two Cloudflare Pages sites, then publish source and release artifacts to GitHub.

**Architecture:** Use the existing Electron/Vite application and electron-builder targets. Keep Campfire Desktop and CampfireWeb builds separate, generate checksums for every release artifact, deploy the marketing website to `campfire-br` and the authenticated web application to `campfireweb`, and only then update `blckbr/campfire` and create tag/release `v1.1.0`.

**Tech Stack:** Electron 43, electron-builder 26, React 19, Vite 7, TypeScript 5.8, Cloudflare Wrangler, Git/GitHub.

**Spec:** User request in the current conversation.

## Global Constraints

- Release version is exactly `1.1.0` / tag `v1.1.0`.
- Windows target: x64 NSIS installer.
- Linux targets: x86_64 RPM and x86_64 AppImage.
- RPM is intended for RHEL/Red Hat/Rocky/Alma/Fedora-family distributions.
- Publish `campfire-br.pages.dev` and `campfireweb.pages.dev` before GitHub.
- Do not publish GitHub until all requested builds and Cloudflare deploys are verified.
- Preserve existing Campfire functionality and OAuth R3 fix.
- Never include secrets, `.env`, `node_modules`, `dist`, or `release` in source commits.
